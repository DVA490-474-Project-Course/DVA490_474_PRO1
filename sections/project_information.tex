\section{Project information}
\label{section:project_information}

% Project
This paper covers the project plan for the the project Multi-robot Soccer - RoboCup. This project is a collaboration between \ac{mdu}, \ac{udea} and \ac{utp}. This collaboration is part of the internationalization of the Robotics program at \ac{mdu} and is meant to improve the students skills at working in larger multi cultured groups. The project is about developing both the hardware and the software for one \ac{ssl}-RoboCup division B robot. 
% Contributors
The project team consists of eleven contributors split into a hardware and a software team, see Table.\:\ref{tab:contributors_roles}. 
% Software
The software team was further divided into communication, individual robot behaviour and collective robot behaviour.
% Hardware
The hardware team was split into four groups: powertrain \& electronics, sensors \& embedded systems, 3D-\acs{cad} \& body design and mechanical design.
